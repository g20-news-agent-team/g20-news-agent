## 首版框架

从规定信源采集、清洗和去重，将正文与来源信息存入统一资料库。首版用户入口包括热点推送、智能问答、通稿研读和选题工作台。用户可以将材料及原文引用加入工作台分区，从同一分区的材料中生成可编辑、复制或导出的结构化选题单。

按两张图的图例，订阅、工具包和分区共享及团队协作属于后续开发。

## 开发分工与推进顺序

### 第一阶段：数据采集、预处理与数据库

- 数据采集与预处理：对接项目规定的信源，完成采集、清洗、去重和字段标准化，保留正文与原文链接。
- 数据库：建立统一资料库，对接采集产物的入库流程，验证数据可查询、来源可追溯。

### 第二阶段：按系统架构图逐项联调

资料库可用后，按以下顺序逐项打通。前三项均需验证材料及原文引用能添加至选题工作台的指定分区。

1. 数据 → 热点推送 → 添加至工作台。
2. 数据 → 智能问答 → 添加至工作台。
3. 数据 → 通稿研读 → 添加至工作台。
4. 工具包。
5. 订阅。
