# G20 新闻生产智能体

项目面向新闻传播专业学生和初入行的采编人员，帮助用户从 G20 动态中发现选题、核验原始材料，并形成采访或写作提纲。

## 首版框架

从规定信源采集、清洗和去重，将正文与来源信息存入统一资料库。首版用户入口包括热点推送、智能问答、通稿研读和选题工作台。用户可以将材料及原文引用加入工作台分区，从同一分区的材料中生成可编辑、复制或导出的结构化选题单。

按两张图的图例，订阅、工具包和分区共享及团队协作属于后续开发。
